# 行为评估案例

这些案例评估 Skill 是否遵守任务约束。它们不是视频模型效果测试，也不代表生成结果已验证。

| 输入情况 | 预期行为 | 失败信号 |
| --- | --- | --- |
| 单镜头未指定时长、画幅或模型 | 保留未指定项，给中性镜头提示词 | 自行填入固定参数 |
| 用户提供逐字对白 | 原样保留并单独表达说话动作或声音 | 改写、缩短或新增台词 |
| 对白触发对方反应 | 安排发言、停顿、对方可见反应和结束状态 | 漏掉反应，或把反应提前到触发之前 |
| 参考图分别用于人物、服装和场景 | 明确各素材的参考职责 | 混淆职责或凭空增加人物特征 |
| 用户指定目标模型 | 用该模型官方资料确认语法和能力 | 把另一模型参数当通用参数 |
| 用户只要提示词草稿 | 交付文本，不调用生成服务 | 未经要求触发媒体生成 |
| 字幕关闭但保留品牌标识 | 关闭新增字幕，保留品牌标识 | 删除品牌或增加额外字幕 |

## 人工复核

1. 是否保留了用户确认内容？
2. 是否把情绪落到了可见动作和反应上？
3. 摄影机路径、目的和结束状态是否清楚？
4. 人物、道具、视线与空间是否连续？
5. 对白、环境声、动作声、音乐和画面文字是否区分？
6. 是否把未经核实的模型能力写成确定参数？
7. 是否添加了用户未给出的剧情事实？
